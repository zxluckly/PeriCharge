# 外设电量监控

Windows 10 / 11 下的轻量托盘工具：把外设电量直接摆在任务栏右侧。手柄、键盘、鼠标还剩多少电，
一眼就能看到，不用切窗口，也不用装厂商驱动。

## 功能

- **任务栏悬浮条**：设备名 + 电量胶囊并排显示，多台外设同时可见
- **设备多了自动压缩**：超过 3 台时去掉设备名、只留图标 + 电量胶囊，电量始终在条上；
  鼠标移上去弹出详情面板，一次列全每台的名字、电量和充电状态
- **压缩行为可调**：菜单「显示压缩」里可以选是否始终紧凑、超过几台开始压缩（2–6 台）、
  紧凑样式（图标 + 电量胶囊 / 仅图标）
- **电量配色**：> 50% 绿色 / 21–50% 琥珀 / ≤ 20% 红色，托盘图标与胶囊同步换色
- **充电与充满分开标记**：充电中显示 `⚡`，充满显示 `✦`。DualSense 读的是 HID 报告里的真实充电状态
- **悬停即刷新**：点悬浮条上的刷新按钮或托盘图标左键，立刻重读
- **跟随系统亮暗主题**：菜单、悬浮条、详情面板、文字颜色随系统切换，不用重启
- **只显示读得到的设备**：关机、休眠、没有标准电池服务的设备不会出现在列表里
- **插拔即时响应**：监听设备变化，插上就重新枚举，不用等下一轮定时刷新
- **单实例**：重复启动会提示「已在运行」；配置和日志只写 `%APPDATA%\PeripheralBattery`

## 支持的外设

| 设备 | USB | 蓝牙 | 说明 |
|---|---|---|---|
| DualSense (PS5) | ✅ | ✅ | 解析 HID 输入报告，能区分充电中 / 已充满 |
| 墨将（BIGBIG WON）2.4G 手柄 | ✅ | — | 走接收器的厂商通道主动查询，实测与官方助手读数一致 |
| Xbox 无线手柄 | — | ✅ | 标准 GATT 电池服务，需处于连接状态 |
| BLE 键盘 / 鼠标（如 R75Pro） | — | ✅ | 标准 GATT 电池服务 |
| 其他品牌 2.4G 接收器 | ⚠️ | — | 能识别出设备，但各家私有协议未逐个适配 |
| 经典蓝牙耳机 / 鼠标 | — | ⚠️ | 依赖 HFP 上报，多数设备不提供 |

## 快速开始

1. 到 [Releases](https://github.com/zxluckly/PeriCharge/releases) 下载 `PeriCharge-v0.4.0.zip`
2. 解压，双击 `PeripheralBattery.exe` —— 没有主窗口，直接进托盘
3. 想开机自启：右键托盘图标 → 勾选「开机自动启动」

首次运行若被 SmartScreen 拦下（程序未签名），点「更多信息 → 仍要运行」。
运行时使用系统自带的 .NET Framework 4.8，不需要额外安装运行库。

## 使用

右键托盘图标：

| 菜单项 | 作用 |
|---|---|
| 设备名（勾选项） | 勾掉即从悬浮条和托盘提示里隐藏这台设备 |
| 立即刷新 | 重读一遍，并顺带全量扫描一次 |
| 重新扫描设备 | 同上，用于新设备没被自动发现时 |
| 识别 HID 设备（VID/PID） | 列出本机 HID 接口，排查设备是否被识别 |
| 在任务栏显示电量 | 悬浮条总开关 |
| 显示压缩 | 是否始终紧凑、压缩阈值、紧凑样式 |
| 悬停背景 | 颜色任选、不透明度 20%–100%，或恢复成跟随系统 |
| 开机自动启动 | 写入当前用户的启动项 |
| 退出 | 关闭程序 |

托盘图标左键单击 = 立即刷新。

## 已知限制

- 悬浮条固定在主显示器任务栏右侧；多显示器、任务栏放在顶部或侧边未适配
- 2.4G 接收器目前只适配了墨将（`VID_413D` / `PID_2104`）
- 墨将官方助手运行时会独占厂商通道，此时读不到墨将手柄电量
- 经典蓝牙 HFP 电量未接入；没有低电量提醒
- 未签名，首次运行会触发 SmartScreen
