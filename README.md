# 外设电量监控 (PeriCharge)

Windows 10 / 11 下的轻量托盘工具：把蓝牙外设的电量直接摆在任务栏右侧。手柄、键盘、鼠标还剩多少电，
不点开任何设置就能看见。

单文件 exe，免安装、免管理员权限、不写注册表，双击即用。

*默认状态：背景完全透明，只留设备图标、名称和电量胶囊，不遮挡任务栏本身。*

![悬停状态](docs/images/taskbar-overlay-3.png)

*鼠标悬停：背景浮起、边缘出现描边，右侧多出一个刷新按钮。移开即恢复透明。*

## 功能

- **任务栏悬浮条**：常驻任务栏右侧，设备名 + 电量胶囊并排显示，多台外设同时可见
- **电量配色**：> 50% 绿色 / 21–50% 琥珀 / ≤ 20% 红色，托盘图标与胶囊同步换色
- **充电与充满分开标记**：充电中显示 `⚡`，充满显示 `✦`。DualSense 读的是 HID 报告里的真实充电状态，
  不是靠「插了线」推测
- **悬停即刷新**：鼠标移上去背景浮起并出现刷新按钮，点一下立刻重读；托盘图标左键单击同样是刷新
- **悬停背景可调**：颜色任选、不透明度 20%–100% 五档（默认 60%），也可一键恢复成跟随系统颜色
- **跟随系统亮暗主题**：菜单、悬浮条、文字颜色随系统切换
- **只显示读得到的设备**：关机、休眠、没有标准电池服务的设备不会出现在列表里，也不会残留旧数字
- **不伪造精度**：手柄只上报固定档位，就按档位换算显示（等级 7 → 约 75%），不编中间值
- **插拔即时响应**：监听 `WM_DEVICECHANGE`，插上设备立刻重新枚举，不用等下一轮定时刷新
- **资源管理器重启不崩**：监听 `TaskbarCreated` 广播自动重建悬浮条，重新挂回新任务栏
- **单实例**：重复启动会提示「已在运行」，不会出现两条悬浮条
- 配置和日志只写 `%APPDATA%\PeripheralBattery`，日志超过 1 MB 自动轮转，长期挂着不会无限增长

## 支持的外设

| 设备 | USB | 蓝牙 | 说明 |
|---|---|---|---|
| DualSense (PS5) | ✅ | ✅ | 解析 HID 输入报告：低 4 位是电量档位（11 档），高 4 位是充电状态 |
| Xbox 无线手柄 | — | ✅ | 标准 GATT 电池服务，需处于连接状态 |
| BLE 键盘 / 鼠标（如 R75Pro） | — | ✅ | 标准 GATT 电池服务（`0x180F` / `0x2A19`） |
| 2.4G USB 接收器 | ⚠️ | — | 能识别出 VID/PID 与用途页，但电量走厂商私有协议，尚未适配 |
| 经典蓝牙耳机 / 鼠标 | — | ⚠️ | 依赖 HFP 上报，多数设备不提供 |

DualSense 同时插 USB 又连着蓝牙时，Windows 会暴露两个 HID 节点，程序会把它们合并成一条，保留 USB 读数。

## 快速开始

1. 到 [Releases](https://github.com/zxluckly/PeriCharge/releases) 下载 `PeriCharge-v0.2.0.zip`
2. 解压，双击 `PeripheralBattery.exe` —— 没有主窗口，直接进托盘
3. 想开机自启：右键托盘图标 → 勾选「开机自动启动」

首次运行若被 SmartScreen 拦下（程序未签名），点「更多信息 → 仍要运行」。

运行时使用系统自带的 .NET Framework 4.8，不需要额外安装运行库。

## 使用

右键托盘图标：

| 菜单项 | 作用 |
|---|---|
| 设备列表（勾选项） | 取消勾选即从悬浮条和托盘隐藏该设备 |
| 立即刷新 | 重读一次，并顺带全量扫描 |
| 重新扫描设备 | 重新枚举已配对设备，找回刚上线的外设 |
| 识别 HID 设备（VID/PID） | 列出本机 HID 接口的 VID/PID、产品名、用途页、报告长度，用于判断设备类型 |
| 在任务栏显示电量 | 悬浮条开关 |
| 悬停背景 | 选择颜色 / 不透明度 20%–100% / 恢复默认（跟随系统颜色） |
| 开机自动启动 | 写入启动项 |
| 退出 | 关闭程序 |

托盘图标的颜色取自当前在线设备里电量最低的那台，鼠标悬停显示全部设备的电量。

## 配置文件

`%APPDATA%\PeripheralBattery\settings.ini`，删掉即恢复默认：

| 键 | 默认 | 说明 |
|---|---|---|
| `configVersion` | `2` | 配置格式版本，程序自动维护，不用手改 |
| `showTaskbar` | `1` | 是否显示任务栏悬浮条 |
| `refreshSeconds` | `30` | 自动刷新间隔（秒），最小 10 |
| `hiddenIds` | 空 | 被隐藏的设备 ID，`\|` 分隔 |
| `hoverColor` | `0` | 悬停背景色（ARGB 整数），`0` = 颜色跟随系统主题 |
| `hoverAlpha` | `153` | 悬停背景不透明度 1–255，`153` = 60% |

`hoverColor` 只管颜色，`hoverAlpha` 始终生效——即使颜色跟随系统，也能单独调透明度。

日志在 `%APPDATA%\PeripheralBattery\log.txt`，超过 1 MB 轮转为 `log.1.txt`（只留一份）。
刷新耗时超过 3 秒时才会写一条 `刷新耗时 xxx ms`，正常情况不刷屏。

## 从源码构建

需要 Windows 10 / 11、.NET Framework 4.8、以及 Windows SDK 里的 `Windows.winmd`
（`build.bat` 会自动挑最新的 `UnionMetadata\10.*`），**不需要安装 .NET SDK**。

```bat
git clone https://github.com/zxluckly/PeriCharge.git
cd PeriCharge
build.bat
```

产物：`bin\PeripheralBattery.exe`，程序图标取自 `src\app.ico`（`/win32icon` 内嵌，
含 16/20/24/32/40/48/64/128/256 九种尺寸）。

## 已知限制

- 悬浮条固定在主显示器任务栏右侧；多显示器、任务栏放在顶部或侧边未适配
- 2.4G 接收器的私有协议未实现，这类设备只能被识别、读不到电量
- 经典蓝牙 HFP 电量未接入
- 没有低电量提醒
- 未签名，首次运行会触发 SmartScreen
